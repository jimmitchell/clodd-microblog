{{- /* A post's rendered body, finished the way Clodd's Builder finishes one. Arguments (a dict): page — the post kind — its post-kind.html eager — true when the body's first picture is the Largest Contentful Paint element: a photo post's page, an article whose lead picture is in its body, the lead card on the home page 1. Raw tags written as HTML (imported posts have them) get what the render hook gives a Markdown image: WebP sources and dimensions (Clodd's ResponsiveImages::upgrade). Tags already in a , with their own srcset, or not local are left alone, and every attribute the author wrote is kept. 2. On a photo post every gets u-photo. Microformats parsers read a photo post's type from its u-photo, and here the pictures live in the body (Micropub and Micro.blog both put them there) rather than in a field of their own. 3. With eager, the first loads eagerly at high priority (Clodd's promoteFirstImage). 4. An embed script that several embeds brought along (X, Instagram, a Mastodon instance) is kept once, at the end, as Clodd does. */ -}} {{- $page := .page -}} {{- $html := string $page.Content -}} {{- /* 1. Set the s aside so their s aren't touched. */ -}} {{- $pictures := findRE `(?s)` $html -}} {{- range $i, $pic := $pictures -}} {{- $html = replace $html $pic (printf "\x00picture%d\x00" $i) -}} {{- end -}} {{- $attrRE := "([a-zA-Z_:][\\w:.-]*)(?:\\s*=\\s*(?:\"([^\"]*)\"|'([^']*)'|([^\\s\"'=<>`]+)))?" -}} {{- range uniq (findRE `]*>` $html) -}} {{- $tag := . -}} {{- $attrs := dict -}} {{- range findRESubmatch $attrRE (strings.TrimSuffix ">" (strings.TrimSuffix "/>" (strings.TrimPrefix "]*>` $html) -}} {{- $tag := . -}} {{- $new := "" -}} {{- if findRE `\sclass="` $tag 1 -}} {{- $new = replaceRE `(\sclass=")` "${1}u-photo " $tag 1 -}} {{- else -}} {{- $new = replaceRE `^]*>` $html 1 -}} {{- $tag := index . 0 -}} {{- $new := replaceRE `\s(?:loading|decoding|fetchpriority)="[^"]*"` "" $tag -}} {{- $new = replaceRE `\s*/?>$` ` loading="eager" decoding="sync" fetchpriority="high">` $new -}} {{- $html = replace $html $tag $new 1 -}} {{- end -}} {{- end -}} {{- /* 4. One copy of each embed script. */ -}} {{- range uniq (findRE `]*>` $html) -}} {{- if gt (strings.Count . $html) 1 -}} {{- $html = printf "%s\n%s\n" (replace $html . "" | strings.TrimRight "\n ") . -}} {{- end -}} {{- end -}} {{- return $html -}}
